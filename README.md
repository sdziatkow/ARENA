# ARENA

Uses jfx 21.0.7
-----------------
Top down 2D RPG.  
Some art in resources is free-use; it is temporarily being used to develop the sprite systems.  
The only contributor to this project is sdziatkow.

#### Controls:

- Move - WASD
- Menus - I
- Interact - E [while looking at]
- Attack - LMB
